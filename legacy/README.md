# Legacy and superseded implementations

This directory preserves the pre-refactor working tree for provenance and
rollback. Nothing under `legacy/` is part of the canonical execution path.

The active repository is organized under `src/`, `scripts/`, `configs/`,
`data/`, `results/`, `figures/`, and `cluster/`.

Files here are retained rather than deleted because they may document earlier
experiments, diagnostics, or superseded implementations.
