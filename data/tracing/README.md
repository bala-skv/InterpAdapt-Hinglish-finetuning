# Stage 1 tracing data

The current Stage 1 tracing set is `tracing_set_v1.json`.

Each concept contains three matched conditions:

- `en`: English
- `hi_latn`: Romanized Hindi
- `hi_deva`: Devanagari Hindi

Each condition is represented as a prompt/target pair. Prompts end in one
space and targets carry no leading space, matching the Stage 1 scoring contract.

The 38 concepts were reviewed by a native Hindi speaker for semantic
unambiguity and grammatical acceptability before the Stage 1 run.
