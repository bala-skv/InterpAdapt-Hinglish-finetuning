# Stage 2 downstream data

The Stage 2 SAIL-2017 Romanized sentiment artifact is hosted on Hugging Face:

https://huggingface.co/datasets/satyam-arora-iiit-hyderabad/babyshark-sail2017-stage2

Use the `sanitized/` splits for experiments. The repository records the source
provenance, cleaning manifest, checksums, and raw source copy.

Raw source splits: 10,080 train / 1,260 validation / 1,261 test.
Experimental splits: 10,068 train / 1,260 validation / 1,261 test.
